# TemichevVet — первичный план сайта и макетов v1

Дата фиксации: 30.07.2026.

> **Статус документа после решения 05.08.2026:** это ранний вариант единого сайта с веткой `/armavir/`. Состав экранов, требования к gateway, мобильной проверке, заявкам и защите данных сохраняют ценность, но доменная схема ниже больше не является актуальной. Подтверждённая целевая структура: `temichevvet.ru` — федеральный сервис владельцев; `clinic.temichevvet.ru` — местная клиника; `pet.temichevvet.ru` — общий публичный сайт груминга и зоогостиницы; `crm.temichevvet.ru` — продуктовый сайт CRM; `cabinet.temichevvet.ru` — продолжение CRM для подключённых владельцев. `staff.temichevvet.ru` остаётся отдельным служебным контуром удалённого доступа и не является рекламным сайтом. `shop.temichevvet.ru` не публикуется до отдельного решения.
>
> Pet остаётся одним сайтом с двумя разными операционными модулями. Интеграция проектируется как настраиваемая система публичных витрин: один разрешённый сайт может показывать оба модуля, другой — только груминг или только зоогостиницу. Все заявки идут через публичный gateway, явно несут витрину, модуль, филиал и предложение и сначала подтверждаются администратором. Существующие 27 маршрутов ниже следует использовать как инвентарь контента, а не как утверждённые production-адреса.

## 1. Главное решение

TemichevVet строится как единая ветеринарная экосистема, но рекламные сценарии разделяются.

1. `temichevvet.ru/` — общая главная бренда. Она рассказывает о здоровье питомца, системе помощи TemichevVet, враче Константине Темичеве, магазине и продукте для ветклиник. Город не является главным смыслом страницы.
2. `temichevvet.ru/armavir/` — отдельная локальная посадочная для рекламы ветеринарной клиники в Армавире. На ней сразу видны запись, телефон, режим работы, адреса и услуги.
3. `vetklinika-24.ru` — старый сайт «Айболит». На первом этапе продолжает работать как существующая SEO-визитка. Перенос домена, редиректы и изменение старого сайта требуют отдельного решения.

Основная формулировка доверия:

> Константин Темичев — ветеринарный врач, кандидат ветеринарных наук, создатель TemichevVet.

## 2. Верхнее меню общего сайта

- `Здоровье питомца` → `/health/`
- `О враче` → `/doctor/`
- `Магазин` → `/store/`
- `Для ветклиник` → `/for-clinics/`
- отдельный заметный вход `Клиника в Армавире` → `/armavir/`
- кнопка `Войти` → `/cabinet/`

На общей главной не используется размытый пункт «Клиника и услуги». Локальное предложение называется прямо: «Клиника в Армавире».

## 4. Дополнительные состояния

1. Меню мобильной версии: закрыто и открыто.
2. Чат: кнопка, приветствие, форма первого сообщения, отправлено, оператор недоступен.
3. Онлайн-запись: пустая форма, заполнение, проверка ошибок, отправка, успех.
4. Корзина: пустая и с товарами.
5. Поиск: до запроса, результаты, ничего не найдено.
6. Кабинет: вход, ссылка просрочена, приглашение недействительно, помощь.
7. Сервисные состояния: загрузка, ошибка сети, технические работы.

## 5. Две рекламные воронки

### Общая реклама TemichevVet

`реклама → / → оценка состояния → понятный результат → сохранение результата → вход/регистрация`

Допустимые объявления: здоровье питомца, проверка симптомов, история здоровья, рекомендации врача, система TemichevVet.

Основная конверсия: начало оценки состояния. Локальная клиника показана как отдельная возможность, но не перехватывает главный сценарий.

### Локальная реклама Армавира

`реклама по Армавиру → /armavir/ → выбор действия → заявка/звонок/маршрут → подтверждение администратора`

Допустимые объявления: ветеринарная клиника Армавир, круглосуточная помощь, конкретная услуга, груминг, зоогостиница.

Основные конверсии: отправка заявки, звонок, сообщение, построение маршрута. Общая оценка состояния остаётся дополнительной помощью.

## 6. Форма записи и граница CRM

Публичный сайт не обращается напрямую к клинической базе.

Форма отправляет заявку только в защищённый публичный owner-gateway:

- имя;
- телефон;
- кличка питомца;
- вид животного;
- желаемые дата, время и филиал;
- комментарий;
- согласие на обратную связь;
- технический `clientRequestId`;
- безопасные UTM-метки без медицинского текста и персональных идентификаторов.

После отправки пользователь видит: «Заявка получена. Администратор подтвердит время». Заявка не создаёт приём автоматически.
