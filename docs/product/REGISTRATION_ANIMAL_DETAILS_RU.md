# Данные пациента при записи на приём

В очереди и предварительной записи существующий пациент показывает кличку, вид, породу, пол, дату/год рождения и вычисленный возраст. Пропуски выделяются подсказкой; неизвестные сведения не запрещают запись без изменений. Породу можно внести со слов владельца. Пол и возраст не угадываются.

При сохранении изменённые поля отправляются в существующую карточку пациента до создания/изменения записи. Неизменённые поля не перезаписываются. Смена пациента сбрасывает его несохранённый локальный черновик; обновление списка в фоне не перезаписывает текущий ввод. Ошибка сохранения карточки не приводит к созданию записи с потерянными правками. Если карточка сохранена, но последующее создание записи не удалось, данные карточки остаются сохранёнными.

Во всех режимах формы показана дата последнего приёма владельца; у выбранного животного — отдельно дата его последнего приёма. Источник — новейший неотменённый приём, а не запись в расписании. Новая карточка показывает «Приёмов ещё нет», ошибка загрузки — отдельное сообщение, без ложного отсутствия истории. Отсутствующие в перенесённой базе приёмы автоматически не восстанавливаются.

Формы сбрасываются при открытии, а не после завершения анимации: быстрый выбор больше не теряется. Кнопки остаются на экране, содержимое прокручивается, дата владельца закреплена сверху.

Проверки 08.09.2026: API/Web compilation, unit-тесты; изолированный браузер с двумя пациентами — подстановка, смена пациента, неизменённая запись без PATCH, сохранение пола/породы/года без дубликатов, предварительная запись, отсутствие истории у новой карточки, обе даты и визуальная проверка формы. Рабочие карточки для тестирования не редактировались.
