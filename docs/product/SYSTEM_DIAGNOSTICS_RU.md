# Ежедневная самодиагностика TECNO

Автономная задача Windows `TemichevVet Daily Diagnostics` запускается ежедневно в 08:00 по часовому поясу сервера. Пропущенный запуск выполняется при следующей возможности. Codex, MacBook и платные AI-сервисы не нужны. Выключенный компьютер не может диагностировать сам себя; для немедленного оповещения о полном отключении нужен отдельный внешний мониторинг.

Проверяются работа Docker/шести контейнеров, HTTP интерфейса и API с проверкой базы, совпадение API/Web с явно подтверждённой версией, разрешённые Compose-образы и закреплённые образы автообновления, свободное место (20 ГБ), свежесть резервных копий базы (36 ч), файлов (192 ч), отметки проверки целостности (48 ч), наличие непустых архивов и явно неуспешный тест восстановления. Архивы заново не распаковываются, база для теста не создаётся. Отсутствие отметки тестового восстановления не означает, что восстановление проверено.

Клинические записи, настройки и контейнеры диагностический запуск не меняет. Единственные записи в CRM — служебная новость с аудиторией `director` и запись системного аудита. Повтор одной и той же проблемы не создаёт новые сообщения; восстановление отмечается отдельным сообщением. Если Docker/API/база недоступны, событие остаётся в локальном отчёте и повторяется при следующем запуске. Безработный API не способен показывать уведомление: в таком случае доступны локальный отчёт и журнал Windows, а уведомление в CRM придёт после восстановления при следующей проверке.

Отчёты: `<CRM>\diagnostics\latest.json`, ежедневная история `checks\YYYY-MM-DD.json`, журнал Windows Application / `TemichevVet Diagnostics`. Код и конфигурация планировщика в `diagnostics\bin` защищены от записи обычными пользователями. Задача работает от SYSTEM, не зависит от интерактивного входа пользователя; Docker Desktop при этом должен быть запущен обычным способом. Код возврата 1 означает обнаруженную проблему или недоставленное уведомление, 0 — успешную проверку.

Установка из административного PowerShell:

```powershell
.\scripts\install-system-diagnostics.ps1 -Root C:\Users\TemichevVet\TemichevVet -ExpectedHost WIN-I123AM83GR4 -ExpectedRevision <полный_SHA_проверенного_релиза>
Start-ScheduledTask -TaskName 'TemichevVet Daily Diagnostics'
```

После каждого согласованного релиза повторить установку с новым SHA: скрипт принимает только уже работающие API/Web с этой ревизией. Эталон не обновляется автоматически вслед за контейнером — иначе откат стал бы незаметен. Предыдущая конфигурация эталона сохраняется. До обновления эталона законный новый релиз также вызовет предупреждение, это ожидаемая защита.

Отключение без удаления истории: `Disable-ScheduledTask -TaskName 'TemichevVet Daily Diagnostics'`. Самодиагностика не выполняет автоматических откатов, перезапусков, исправлений, публикаций или обновления образов.

## Мобильная CRM и удалённый просмотр

На экранах до 767 px глобальные служебные плашки скрыты, а уведомления, состояние удалённого доступа и ссылка на непрочитанные сообщения доступны в колокольчике. Активные просроченные приёмы/вакцинации остаются в списке и после прочтения. Настольные плашки сохранены.

Доверенное удалённое устройство активного сотрудника без роли директора может входить и просматривать разрешённые роли разделы вне смены. Проверка доверия, принадлежности устройства, отзыва и политики удалённого доступа остаётся обязательной; локальный вход по сменам не меняется. Сервер по-прежнему запрещает рабочие POST/PATCH/PUT/DELETE; личные служебные действия (выход, пароль, отметки прочтения, существующая переписка) сохраняют прежние разрешения. Права директора не расширяются этой льготой.

Единые значки вкладки, apple-touch и manifest используют ранее утверждённые файлы логотипа. Для старого ярлыка iPhone может потребоваться удалить только ярлык и добавить сайт на домашний экран заново. Буква в аватаре сотрудника — его инициалы, а не иконка приложения; она не заменяется логотипом.
