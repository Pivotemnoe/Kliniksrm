# Исправления зоогостиницы: владельцы и цены боксов

Выложено 23 октября 2026, 12:56 МСК. Приёмка рабочей базы завершена в 13:09 МСК. Версия приложения: `c43e0e8c8dd46de80a4616072b1a8f9d2826d1c1`.

Администратор может создать нового владельца с питомцем непосредственно в форме брони зоогостиницы. Предварительное создание карточки в клинике не требуется. Владелец доступен для повторного поиска. Регистрация не создаёт клинических визитов, приёмов или счетов.

Во вкладке «Номера и тарифы» у каждого бокса есть «Изменить цену». Администратор получил право `pet_hotel.manage`; право подключения/отключения модулей `modules.manage` не расширялось.

## Приёмка

- Локально: API/Web собраны, типы и интеграционные проверки пройдены; сохранение брони проверено после перезапуска и повторного входа.
- На восстановленной рабочей базе: новый владелец, новый питомец, повтор команды без дублей, дополнительный питомец; изменение и повторное открытие цен всех 12 номеров; 2 суток и 3 часа считаются как 3 суток; тариф уже сохранённой брони не меняется. Содержимое 11 защищённых клинических и смежных таблиц осталось точным.
- На боевой CRM под временным администратором с тремя правами гостиницы, без прав на владельцев/животных клиники: новый владелец и кошка созданы через экран CRM, найдены и выбраны после перезагрузки.
- Все 12 рабочих номеров сохранены и прочитаны повторно с прежними тарифами. В интерфейсе видны 12 кнопок изменения цены. Новая цена отдельно проверена на неактивном тестовом номере: 111,11 → 222,22 ₽ через API, затем 333,33 ₽ через экран CRM, перезагрузка и повторное открытие редактора.
- Тестовые владелец, питомец и неактивный номер удалены. Временный сотрудник заблокирован, его роли и сессии отозваны; журнал приёмки сохранён. В рабочей гостинице остались исходные 12 номеров с прежними тарифами.
- API и база отвечают штатно; новая версия подтверждена через `staff.temichevvet.ru/release.json`. Условия гостиницы, настройки груминга и Авито сохранены. Настоящие брони и отправки MAX в боевой приёмке не создавались.

До замены контейнеров Docker на TECNO перестал отвечать, после чего рабочий сайт отдавал 502. Движок восстановлен через существующую задачу `TemichevVet Docker Boot`. Идентификаторы контейнеров, образы, конфигурация и тарифы совпали с исходным снимком; временные метки запуска обновлены. После восстановления снята и проверена свежая резервная копия. Первичная причина выхода Docker этим выпуском не установлена.

После подготовки заменялись только API и Web; PostgreSQL, Redis, MinIO и служба резервного копирования при переключении приложения сохранили идентификаторы и время запуска после восстановления движка.
