# Оповещения Авито в CRM — 2 ноября 2026

Сообщения сохранялись в модуле Авито, но StaffAlertsService не включал их в общий центр оповещений. Теперь администратор и директор с правом avito.read видят группу «Сообщения Авито», счётчик на колокольчике и кнопку Авито в общей рабочей панели. Нажатие открывает нужное направление и диалог.

Прочтение сохраняется отдельно для сотрудника и версии входящего сообщения. Ответ бота, синхронизация и изменение контактов не создают дубликаты; новое сообщение снова становится непрочитанным, в том числе при одинаковом времени Авито с точностью до секунды. Системные сообщения и архив до подключения исключены. Просмотр в фоновой вкладке не подтверждает прочтение. Центр обновляется опросом CRM каждые 30 секунд после сохранения сообщения локально; существующий цикл синхронизации Авито сохранён. Это оповещения внутри CRM; мобильная push-подсистема не менялась.

По прямому указанию владельца добавлена отдельная действующая строка «Той-пудель · Полный комплекс» за 2500 ₽ с мытьём, без повторной прибавки 300 ₽. Все прежние 172 цены и карликовый пудель сохранены. Позиция хранится в CRM с происхождением OWNER_CONFIRMED и аудиторской квитанцией; импорт исходного каталога сохраняет существующие и дополнительные строки. Гигиена и длительность для новой позиции не выдуманы.

API установлен поверх точного работающего образа, с сохранением трёх read-only overlays Android/iOS. Web собран из воспроизведённой фактической версии 30 октября; её исходный overlay hash совпал с установленной меткой. Сначала изменены только восемь файлов уведомлений, затем одна проверка видимости вкладки. Очередь, UUID рабочего места, остальные модули, права и прежние хешированные assets сохранены.

Проверены 49 целевых unit и 2 интеграционных сценария на отдельном локальном PostgreSQL, 20 случаев отказов издателя в Windows PowerShell 5.1, переход в диалог через браузер на синтетических данных и read-only повтор исходного запроса на сервере. Последний подтвердил 2500 ₽ для той-пуделя, сохранение возраста и вопросов об обработке/визите, прежние цены карликового пуделя и йорка, а также шесть реальных локально сохранённых кандидатов оповещений. Клиенту тестовые сообщения не отправлялись, его режим HUMAN сохранён.

Публичный интерфейс после замены отвечает; в браузере потребовался вход, поэтому реальная авторизованная UI-приёмка сотрудником не заявляется. После сохранения незаконченного ввода сотрудникам нужно обновить CRM, чтобы загрузить новую сборку.

Резервная копия базы восстановлена и сверена в изолированной среде по 158 таблицам, 57 физическим файлам и 18 активным ссылкам. Для однострочного Web-исправления повторно проверены и скопированы те же квалифицированные байты; новая проверка восстановления не заявляется. Боевая база не восстанавливалась. Исходные состояния выпусков сохранены. Отдельная производная квалификация API учитывает оба разрешённых обновления Web и добавленную цену; она проверена без повторной установки API. Откат API по этой квалификации сохраняет цену и текущий Web. Старые операторы, ожидающие 172 строки или прежний Web, использовать без новой квалификации нельзя.

Санитизированная квитанция: verification.json. Прямое подтверждение цены: owner-confirmed-price.json. Приватные планы, резервные копии конфигурации и полные квитанции остаются вне Git.
