# Логотипы и автосохранение рекомендаций — 26 сентября 2026

## Изменения

- Приём и стационар получают реквизиты из разрешённого врачам печатного профиля, а не из административных настроек. Права на настройки не расширяются.
- Печатные формы приёма, назначений, стационара, бокса, лаборатории, составных документов, счетов, приглашений и отчётов показывают логотип. Загруженный логотип имеет приоритет; при его отсутствии/ошибке загрузки браузер использует комплектный TemichevVet. Печать ждёт декодирования изображения и шрифтов; таймер, удалявший логотип через две секунды, убран.
- Составные PDF A4/A5 содержат логотип и при отключённом названии клиники. Ранее сформированные и сохранённые PDF не переписываются: новый вид применяется при новом формировании документа.
- План лечения и рекомендации владельцу автоматически сохраняются через 900 мс после ввода. Черновик записывается сразу в текущем браузере. Временный обрыв связи не удаляет черновик; есть повтор при восстановлении связи, фокусе окна и каждые 15 секунд.
- Запросы рекомендаций выполняются последовательно для каждого приёма. Успех старого запроса не удаляет новый черновик. Очистка поля отправляет пустую строку, а не пропускает поле. Переход между пациентами разделён ключом приёма.
- Кнопка ручного сохранения остаётся. Проверка обязательного диагноза и правила завершения приёма не изменены. Инструкция внутри CRM обновлена.

## Проверка

Автоматические проверки, локальный интерфейс с синтетическим пациентом: ввод без кнопки, перезагрузка, ошибка связи, восстановление локального черновика, автоматическая повторная отправка. Проверка PDF выполняется по сохранённому файлу и его изображению, а не только по открытию диалога печати.

## Выпуск

Только API/web CRM на TECNO; миграций БД нет. Перед обновлением — резервная копия PostgreSQL и конфигурации, проверка точных ревизий образов. После — API/БД health, ревизии, доступность web и отсутствие перезапусков. PostgreSQL, Redis, MinIO, backup и публичный сайт не обновляются.
