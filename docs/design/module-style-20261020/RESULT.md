# Единый стиль модулей — локальная приёмка 20 октября 2026

Основание: привести Авито и груминг к принятому оформлению CRM — кабинет, оповещения, различимые иконки и компактные действия на телефоне. Проверить локально и показать Константину. Выкладка на боевую не разрешена и не выполнялась.

## Что реализовано

- Общая тема `shared/theme/crmTheme.ts`: принятые цвета, Inter/system font, поверхности и контролы CRM. Её используют основная оболочка и отдельный кабинет грумера.
- В кабинете грумера — общая тёмная навигация, рабочая шапка, личный счётчик, мобильное меню и меню сотрудника. Клинические пункты и директорские настройки грумеру не добавлены.
- В оповещениях — новые/все, поиск, группы записей, переносов, отмен, информации и предыдущих событий. Событие ведёт к записи; просмотр не меняет её статус. Настройка телефона и журнал доставки раскрываются отдельно. Ошибки доставки остаются заметными, служебные коды заменены понятными подписями.
- В Авито — единый компактный блок состояния вместо нескольких служебных баннеров. Режим отправки всегда виден; проблемы подключения, данных и доставки не спрятаны в подробности. Цвета переписки и редактора согласованы с CRM.
- `ModuleActions` сохраняет основное действие видимым на телефоне, вторичные переносит в меню «Ещё». Применено к панели груминга, Авито и действиям редактора объявлений. Установка PWA доступна через «На телефон».
- Разные иконки: ножницы для груминга, робот для Авито, календарь для расписания. Иконки приёмов и отчёта по вакцинациям сохраняются различимыми.
- Кабинет владельца груминга использует общую палитру, типографику и контролы. Основной кабинет, паспорт питомца и продвижение TemichevVet сохранены. Фотографическая композиция публичного сайта не переделывалась.
- Убрана пустая строка мобильной шапки у ролей без глобального поиска. Для оповещений оставлен один опрашивающий компонент, остальные читают общий кэш.

## Локальные интерфейсы

| Адрес | Назначение |
| --- | --- |
| http://127.0.0.1:4281/grooming/calendar?date=2026-10-22 | Груминг внутри CRM, синтетический директор |
| http://127.0.0.1:4282/avito?tab=inbox | Авито, синтетические диалоги и отдельная база |
| http://127.0.0.1:4283/grooming/notifications | Отдельный кабинет синтетического грумера |
| http://127.0.0.1:4284/portal/grooming | Кабинет синтетического владельца |
| http://127.0.0.1:4281/__qa/report | Снимки и ссылки для просмотра |

Предпросмотры обслуживает `node scripts/module-style/preview.mjs`. Они используют фиксированные локальные сборки. Cookie разделены между тестовыми интерфейсами, обычные локальные/боевые сессии не перезаписываются.

Груминг использует согласованные соседним чатом синтетические API 4271/4273 и БД `grooming_*_integration_preview`. Авито использует отдельный замороженный QA API 4300 с базой `avito_style_qa_20261020`, поддельным транспортом и запретом внешних запросов. Рабочий пилот Авито 4020/4021 не менялся. В Авито тестовая аутентификация адаптера не заменяет отдельную проверку реального клинического входа при будущей интеграции.

Это локальная сборка интерфейсов с отдельными синтетическими API. Она не является новым комплектом для боевого выпуска. При подготовке будущего выпуска нужно сохранить серверные модули и миграции обоих направлений, а также принятые исправления накладных.
