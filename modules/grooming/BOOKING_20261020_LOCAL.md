# Запись и прайс: локальная версия 20.10.2026

Новая интеграция проверяется локально. Прямое указание пользователя в согласованном чате редизайна: сначала локально, на боевую не публиковать. Рабочие CRM, бот/webhook и публичный сайт r2 не меняются.

Объединены принятые исходники API 956648a и Web 0256e2e. Изменения основного интерфейса остаются внутри grooming feature; авторизация, сброс кеша сотрудника, operationKey для HTTP, большие накладные и Авито сохраняются.

Общий утверждённый прайс находится в apps/api/src/modules/grooming/price-catalog.json. Прибавка 300 ₽ уже применена. Импорт создаёт 218 позиций с диапазонами, «до», процентом, часовой единицей и доплатами. Повтор не пересоздаёт строки и не заменяет ручные изменения. Существующая бронь хранит собственный ценовой снимок.

API передаёт шлюзу только услуги, публичные имена специалистов и собственные рабочие/занятые интервалы. В публичном ответе нет владельцев, питомцев, телефонов, MAX user_id или персональных записей. Давность расписания более 90 секунд закрывает выдачу свободного времени. Сайт выбирает услугу/грумера/дату/время; opaque draft переносит выбор в кабинет. После входа и выбора своего питомца CRM повторно проверяет условия и занятость, затем в одной транзакции сохраняет бронь и очереди уведомлений.

Календарь открывается в виде месяца: счётчики, занятые дни и раскрытие дня. «Составить расписание» заполняет период по дням недели, специалистам и часам. Предварительная проверка не пишет данные, сохранение атомарно отклоняет пересечения. «Добавить смену» создаёт один день. Прежние смены/перерывы редактируются во вкладке специалистов.

Тестовые данные пользователя: Темичев Константин, сегодня 20.10.2026 10:00–17:00 МСК; небольшая собака — 90 минут, крупная — 180 минут. Для этого прогона буфер равен нулю, шаг возможного начала — 15 минут. В синтетическом стенде используются бишон и хаски; другие процедуры/виды без заданной длительности не открываются для самозаписи. Тестовая запись ограничена прежним подтверждённым MAX пользователя. Клиент и назначенный грумер получают отдельные уведомления/напоминания; старый адресат при перепривязке не получает последующие сообщения.
