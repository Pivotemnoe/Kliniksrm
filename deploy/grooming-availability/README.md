Исправляет отсутствовавший GET `/v1/public/grooming/availability` на pet.temichevvet.ru. До исправления публичный сайт отвечал 404 HTML, а тот же запрос кабинету возвращал корректный JSON. Без этого маршрута включение расписания в CRM не давало бы посетителям выбрать время.

Изменение копирует ровно один существующий GET location каталога с теми же upstream, заголовками и таймаутами. POST и неизвестные `/v1`/`internal` остаются закрыты. Самозапись не включается, услуги/специалисты/смены/данные не меняются.

`release.py prepare --expected-nginx-sha256 SHA` сохраняет исходный vhost и кандидат в `/var/backups/temichevvet-grooming/grooming-availability-20261022-r1`, проверяет полную конфигурацию Nginx с временным include. Проверяются все остальные vhost, оба статических дерева и три контейнера кабинета. `apply` атомарно заменяет только pet vhost, делает nginx -t и graceful reload; при сбое возвращает предыдущий файл. `verify` проверяет JSON через HTTPS с реальной проверкой сертификата и сохранность окружения.

`rollback` возвращает только исходный vhost и отказывается перезаписать последующие изменения этого файла. Текущие статические релизы, конфигурации других сайтов и контейнеры сохраняются. Дамп или восстановление БД для такого изменения не требуется; полная исходная конфигурация сохранена.
