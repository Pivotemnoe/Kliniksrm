# Выпуск зоогостиницы CRM

Разрешён пользователем20.10.2026. Исходная рабочая версия —acd9d429
(округление денег и раздельные оплаты), поверх неё перенесены только коммиты модуля.
Публичный сайт и MAX не входят в этот выпуск. Ссылка видна в модуле, с подписью
о подготовке страницы. После отдельной публикации сайта параметр сборки
VITE_PET_HOTEL_SITE_PUBLISHED=true убирает эту подпись.

Подготовка: api build, web build с VITE_API_BASE_URL=/api, интеграционные тесты.
prepare-context.mjs проверяет хэши всех применённых миграций и допускает ровно
одну новую миграцию20261020130000_pet_hotel_module. Миграция транзакционная.
Исходники не содержат секретов; пакет не включает тестовые данные/учётные записи.

На Windows пакет распаковывается в отдельную папку releases/crm-pet-hotel-20261020-r1.
Сначала build-clinic.ps1: образы собираются без сети из точных текущих слоёв,
все существующиеAPI-файлы вне app.module и clinic-modules должны быть побайтно равны.
Проверяются в том числе расчёты, оплаты, большие накладные, груминг и Авито.
Затем backup-database.ps1 сохраняет БД и конфигурацию под ограниченнымACL,
восстанавливает БД в контейнер без сети, применяет новую миграцию, проверяет
кандидата и неизменность клинических записей. Дамп остаётся на Windows.
Хранилище файлов не изменяется этим выпуском и не восстанавливается при откате.

release-clinic.ps1 -Mode Apply проверяет базовые образы, свежую резервную копию,
хэши конфигурации, миграцию и кандидата. Меняет толькоAPI/Web и их image pins.
PostgreSQL,Redis,MinIO иbackup не пересоздаёт; текущие ключи и настройки не меняет.
После health включает PET_HOTEL и добавляет12 согласованных боксов через сервис
с аудитом от имени директора, без создания тестовых клиентов или броней.

Откат: в той же папке и с теми жеRoot/PackagePath запустить
release-clinic.ps1 -Mode Rollback. Скрипт откажется перезаписывать более поздний
выпуск или изменённую конфигурацию. Предыдущие образы и конфигурация сохраняются;
новые таблицы и текущие записи остаются. Дамп поверх работающей клиники для
отката интерфейса не восстанавливать. Новые размещения можно отдельно отключить
в «Подключаемых модулях», сохранив историю и возможность оформить выезд.
