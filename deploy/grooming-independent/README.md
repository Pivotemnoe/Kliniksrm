# Выпуск независимого груминга, 20.10.2026

Разрешён владельцем после локальной приёмки и проверки физического Android. Эта ветка построена поверх фактической рабочей CRM `ccaea00` с сохранением локального списка объявлений и черновиков Авито. Незавершённый модуль зоогостиницы в выпуск не включён.

Выпуск содержит собственные аккаунты грумеров, рабочие места, график, 218 строк согласованного прайса, подключение конкретного телефона и совместимый backend публичного каталога. Переносится только указанный runtime груминга и сервисы, в которых добавлена граница собственных аккаунтов. Неизменность остальных API и gateway-файлов проверяется по SHA-256 относительно точных текущих контейнеров. Публичные страницы gateway не заменяются.

`prepare-context.mjs` требует чистый коммит, свежие файлы preflight и совпадение всех применённых миграций. Для клиники разрешены ровно три новые миграции груминга; для gateway — таблица `GroomingStorefrontSnapshot`. QA-стенд, тестовые пароли и ключи Push в пакет не включаются.

На каждом хосте: build, затем backup. Резервные копии БД и конфигурации остаются под закрытыми правами на исходных серверах. Дампы восстанавливаются в одноразовых контейнерах без внешней сети, применяются миграции и запускается кандидат. Клинические строки, владельцы, привязки мессенджера и сессии должны сохраниться. Все новые временные контейнеры удаляются адресно после проверки.

`initialize.cjs` добавляет только отсутствующие строки согласованного прайса с аудитом. Не создаёт клиентов, питомцев, броней, телефонов, смен и паролей. Уже существующий тестовый аккаунт груминга классифицируется как GROOMING только при доказанном происхождении, единственной роли groomer, отсутствии дополнительных прав и клинических ссылок. Остальные старые профили не переименовываются и не отвязываются. Самостоятельная запись и существующие MAX-настройки сохраняются.

После успешной проверки backup сначала применяется совместимый backend gateway, затем `release-clinic.ps1 -Mode Apply`. Клинический скрипт меняет только image pins API/Web и ожидаемую ревизию диагностики, выполняет миграции и проверяет health. PostgreSQL, Redis, MinIO, backup, их контейнеры и тома не пересоздаются.

Откат: в каталоге того же пакета выполнить `release-clinic.ps1 -Mode Rollback`, затем `python3 release-gateway.py rollback`. Скрипты отказываются перезаписывать более поздний выпуск или чужие изменения конфигурации. Восстанавливаются прежние образы и конфигурация; текущие записи и новые аддитивные таблицы сохраняются. Не восстанавливать старый дамп поверх работающей клиники для отката интерфейса. Боевые тестовые записи и сообщения MAX при приёмке не создаются.
