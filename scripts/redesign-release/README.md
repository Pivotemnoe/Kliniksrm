## Применение и откат

Из папки проверенного пакета на компьютере клиники:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy RemoteSigned -File .\run-clinic-release.ps1 -Mode Apply
```

Обновляется только Web через `compose up -d --no-deps --no-build --pull never web`. Сценарий сохраняет прежние `.env`, `.env.runtime` и настройки диагностики побайтно. Метки Web и удалённого обновления, а также ожидаемые версии диагностики приводятся к фактическим версиям Web и оставшегося API. Остальные настройки сохраняются.

При неуспешной проверке здоровья или версии прежний Web и настройки возвращаются автоматически. Для ручного отката:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy RemoteSigned -File .\run-clinic-release.ps1 -Mode Rollback
```

Откат меняет только Web и сохранённые настройки. Записи, созданные сотрудниками после обновления, остаются в текущей базе. Восстановление базы из копии для обычного отката дизайна не требуется. Сценарий отказывается перезаписывать чужую последующую версию или изменившиеся настройки.

После применения сохраняется `deployment-receipt.json` с фактическими образами, версиями, временем запуска и проверкой API. Кабинет владельца находится на другом сервере и имеет отдельный статический образ; его состояние отражается отдельно в отчёте выпуска.
