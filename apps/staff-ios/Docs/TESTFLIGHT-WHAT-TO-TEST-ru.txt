Первая версия отдельного CRM-приложения для сотрудников TemichevVet: врачей и грумеров. Владельцы клиники пользуются личным кабинетом PWA.

Важно: общий staff/chat API ещё не развернут на рабочем сервере. До его подключения проверяются установка, запуск, экран настройки адреса CRM, ввод данных и системный интерфейс. Полные сценарии ниже уже проверены локально на вымышленных данных и потребуют доступного HTTPS API для проверки на телефоне.

После подключения API:
• Вход своей учётной записью CRM и привязка телефона одноразовым приглашением; выход и истечение сессии.
• Врач: все приёмы клиники, фильтр своих, карточки, смены, задачи; новая запись только при индивидуальном разрешении.
• Грумер: только своё расписание, поиск клиента по полному телефону, клиент/питомец, запись, перенос, статусы и уточнение длительности.
• Личные сообщения и отдельный общий чат клиники: отправка, ответ, история после перезапуска, непрочитанные, оповещение в открытом приложении.
• Потеря связи: сообщение об отсутствии подтверждения, без автоматического повтора сохранения.

Доставка APNs при закрытом приложении ещё не подключена и не считается проверенной. Финансовых и зарплатных экранов нет.
