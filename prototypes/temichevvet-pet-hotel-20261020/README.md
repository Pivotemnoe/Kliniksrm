# Зоогостиница TemichevVET — вторая локальная версия

Новый просмотр: http://127.0.0.1:4274/pet-hotel/. Будущий публичный адрес: https://pet.temichevvet.ru/pet-hotel/. Сайт в этой задаче не публиковался. Принятый стенд груминга 4261–4264, включая его dist/client, сохранён.

## Что изменено

Большой фотографический главный экран с переключением кошки/собаки и параллаксом; галерея шести реальных фотографий из объявления с фильтрами и просмотром целиком; три ракурса помещений с раскрытием деталей; выбор питомца по фото, желаемые даты/время и закреплённый итог; памятка вещей с сохранением на устройстве; три полноценные статьи (диалоги и отдельные страницы), FAQ, телефон и маршрут. На мобильном нижняя панель появляется после первого экрана. Движение можно отключить; системный reduced motion учитывается.

## Условия

Кошки и собаки, ограничение до 10 кг относится к собакам. Заселение 09:00–18:00, минимум 48 часов, 700 ₽ за оплачиваемые сутки. Неполные сутки округляются вверх: 51 час = 3 суток. Выгул собаки — 150 ₽ за каждый раз. Восемь номеров для кошек со стеклянными дверцами и четыре номера для собак. Эти сведения подтверждены прямыми ответами владельца в этом чате и согласованном чате CRM 20.10.2026.

Корм и миски необходимо привезти. Игрушки, лежанки, туалет и наполнитель — при необходимости. Адрес/телефон принятой клиники: Армавир, Каспарова 27/2, +7 (928) 421-45-42. Фактическое время выезда, наличие подходящего места и окончательный расчёт согласуются с администратором.

Выбор дат и номера не резервирует место. В этой версии добавлены публичные цены каждого номера, доступность из свежего снимка CRM, выбранная стоимость и перенос выбора в общий кабинет владельца. В кабинете доступны интерфейсы выбора питомца, повторной проверки номера, подтверждения, истории, переноса и отмены; запись становится фактом только после успешного ответа клинического обработчика. Медицинский и grooming API страница не вызывает.

Работа разделена с чатом «Редизайн интерфейса CRM — вариант 2»: здесь сайт, owner gateway и кабинет; там клинический модуль PET_HOTEL, индивидуальные цены, права, обработчик бронирования и доставка MAX. Общий контракт находится в `modules/pet-hotel/PUBLIC_PORTAL_CONTRACT.md`. Это локальная подготовка, не выпуск в рабочую CRM.

Текущий просмотр 4274 подключён к изолированному шлюзу 4313. В нём только вымышленные данные: 12 номеров, тестовое отличие тарифа второго кошачьего номера, один тестовый владелец. Источник STATE/OPTIONS — проверочная имитация внешнего контракта, не клиническая база. Подтверждение брони намеренно отключено (`bridgeReady:false`), внешняя отправка MAX заблокирована. Сквозная проверка настоящего обработчика CRM ещё требуется.

## Фотографии

- Два постановочных кадра гостиницы разрешено сохранить. На главном экране и в журнале они подписаны как визуализации на основе помещений.
- Шесть присланных 20.10.2026 скриншотов с Авито использованы как источники фотографий гостей. Убраны рамки сайта и наложения; выполнена бережная AI-обработка качества. Исходные скриншоты сохранены вне public, их SHA-256 и источники записаны в отчёте. Это обработанные фотографии на основе источников, не нетронутые оригиналы.
- Фотографии помещений сохранены для просмотра реального пространства. По дополнению владельца от 20.10.2026 в кадре номера №9 убраны мешки и складируемые предметы за задними окнами; первоначальный ракурс салона с ваннами отложен по дальнейшей правке владельца. Вместо него используется найденный IMG_4806: убрана только белая проволочная клетка с пола, улучшены свет и насыщенность. Геометрия помещений и основное оборудование сохранены, добавленных животных и декора нет. Текущие версии: hotel-inside-4817-clean.jpg и salon-real-4806-retouched.jpg. Предыдущие файлы, отклонённые результаты и оригиналы сохранены отдельно.
- Новый кадр с бишоном и руками грумера пользователь отверг. Его нет ни на одном сайте. Исходный результат генерации сохранён вне public.
- Все 13 HEIC в Downloads, включая дополнительно присланный IMG_4806, и все 6 новых исходных PNG сохранены без изменения байтов.

Подробности: ASSET_PROVENANCE.json, SOURCE_PHOTOS.json, premium-image-prompts.json, real-photo-prompts.json, photo-cleanup-prompts.json, salon-4806-retouch-prompt.json. Исследование: RESEARCH_RU.md.

## Локальный запуск

Из этой папки: `node serve.mjs`. Без шлюза онлайн-запись закрыта; фотографии, предварительный расчёт и звонок доступны. Для синтетической проверки из корня checkout: `node scripts/pet-hotel-gateway-preview.mjs --fixture-readonly`, затем из папки сайта `PET_HOTEL_GATEWAY_ORIGIN=http://127.0.0.1:4313 node serve.mjs`. Учебная ссылка для общего кабинета записывается в приватный ignored-файл `output/pet-hotel-booking-20261020/preview-access.json`; не публиковать его. Порт 4274 привязан только к 127.0.0.1. Buildless HTML/CSS/JS и локальные шрифты. После изменения текстов статей: `node scripts/build-journal.mjs` — отдельные страницы используют те же тексты, что диалоги. Метка локального просмотра и noindex сохранены.

По последнему уточнению владельца IMG_4806 стоит только на странице зоогостиницы: http://127.0.0.1:4274/pet-hotel/#grooming. В отдельном макете груминга http://127.0.0.1:4275/ восстановлена исходная глава «03 / Детали стрижки». В его папке `npm run build:visual`, затем `npm run preview:visual`. Этот вариант сохраняет дизайн и каталог, использует только снимок публичного прайса 218 услуг и передаёт действия записи в принятый 4264. Снимок для просмотра генерируется в сборку только с флагом VITE_GROOMING_VISUAL_PREVIEW=1; обычная сборка продолжает работать с прежними API/Booking. Настройки API, MAX и баз не менялись.

В public нет исходных скриншотов с элементами Авито, посторонним текстом или отвергнутого кадра. При будущем разрешённом выпуске отдельно согласуются публикация, актуальная конфигурация CRM и окончательный набор фотографий.

## Проверка текущего соединения

`npm run owner-gateway:build`; `node --test tests/pet-hotel-gateway.integration.test.mjs` (реальные HTTP и отдельная PostgreSQL QA-база, 10 проверок); `node --test tests/owner-gateway.test.mjs` (8 проверок прежней общей авторизации/парсеров); `npm run check --prefix prototypes/temichevvet-pet-hotel-20261020`. Браузерная проверка отдельно подтверждает расчёт индивидуального тарифа, сброс выбора при смене дат, ограничение веса, выгул и передачу дат/номера в кабинет. Эти проверки не подтверждают боевую бронь, доставку MAX или публикацию.
