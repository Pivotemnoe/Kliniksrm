# Прямая задача владельца: довести рабочий сценарий груминга — 20.10.2026

Передана в авторизованный пользователем чат «Редизайн интерфейса CRM — вариант 2», thread 01a15291-15d7-7f90-8546-cd22d3e0fee9. Владелец прямо разрешил передать ответственному чату. Новый визуал сайта не считается решением этой задачи.

## Обязательный результат

- Отдельный подключаемый модуль «Груминг» с видимыми действиями «Добавить грумера», «Добавить рабочее место», «Составить расписание», «Записать клиента».
- Учётная запись и профиль грумера создаются из модуля. Доступ ограничен грумингом; клинические разделы и данные не становятся доступны из-за создания общей платформенной учётки.
- Сейчас реально два рабочих места: «Рабочее место 1» и «Рабочее место 2», по столам. Дальше можно создать №3 и другие. Это отдельные ресурсы груминга.
- Назначение грумера на стол, рабочее время пары грумер+место, брони. Календарь на месяц и реальная свободная длительность для самостоятельной записи с сайта.
- Понятное начало в пустом модуле и актуальные встроенные инструкции. Администратор должен выполнить всю цепочку без поиска создания сотрудника в разделах клиники.

## Найденный пробел в базовом исходнике 663

`apps/web/src/features/grooming/GroomingPage.tsx:121`: кнопка «Добавить специалиста» открывает профиль с выбором уже существующего employeeId. Создания нового сотрудника в этой форме нет.

В строке 158 «Добавить рабочее место» заблокировано без отдельной записи «Место груминга». Два уровня ресурсов с похожими названиями скрывают фактический порядок начала работы.

Это наблюдение исходника, не утверждение о текущей ревизии production. Наличие API и ранее пройденные технические сценарии не подтверждают понятность пользовательского старта.

## Приёмка

В отдельной безопасной среде под администратором: пустой модуль → создать грумера → создать столы 1/2 → назначить смену → записать клиента → увидеть запись у выбранного грумера/стола. Затем войти как этот грумер: проверить доступ только к своим разрешённым операциям груминга и отсутствие клинического доступа. Проверить встроенную инструкцию по фактически существующим кнопкам. Никакие фиктивные сотрудники, смены или брони не создаются в боевой базе ради проверки.

Визуальный сайт остаётся в этом checkout; функциональные изменения CRM выполняет согласованный CRM-чат в своём checkout. Его отдельное разрешение на выпуск модуля гостиницы не означает публикацию нового сайта.

## Дополнение владельца — цены услуг и каждого номера

Передано в тот же авторизованный CRM-чат 20.10.2026 после скриншотов 16:50–16:51.

- Во всём интерфейсе гостиницы использовать «номер / номера». При переименовании сохранить внутренние идентификаторы, связи и историю. Подтверждённая вместимость: 8 номеров для кошек и 4 номера для собак.
- В модуле груминга администратор должен просто открыть услугу и изменить её цену. Сохранить фиксированные цены, диапазоны, верхнюю границу, почасовую единицу, денежные доплаты, проценты и расчёт по согласованию. Каталог версии grooming-prices-20261020-300 уже содержит прибавку 300 ₽; повторно её не применять.
- В модуле зоогостиницы у каждого номера собственная редактируемая цена за сутки. Начальный общий тариф 700 ₽ можно использовать как исходное значение; изменение одного номера не меняет остальные.
- Новая бронь использует тариф выбранного номера и сохраняет снимок этого тарифа. Последующее редактирование номера не переписывает сумму ранее сохранённой брони.
- Приёмка: изменить только один номер → закрыть и открыть его снова → убедиться в сохранении → новая бронь получает новую цену → старая бронь сохраняет прежнюю → соседний номер не изменён. Это дополнение к отдельности модуля, правам сотрудников и понятным встроенным инструкциям.

Фактический статус этого дополнения проверяется по ответу CRM-чата. Локальная фотографическая правка сайта сама по себе не создаёт редактирование цен в CRM и не подключает расчёт сайта к тарифам номеров.

Ответ CRM-чата получен: термин «номера», индивидуальные цены и сохранение снимка тарифа приняты. Индивидуальные тарифы гостиницы оставлены следующим отдельным этапом после текущей приёмки самостоятельного груминга. Чат сообщил о локальных HTTP-проверках отдельного аккаунта грумера, каталога 218 цен, двух рабочих мест, смены/брони и привязки телефона; это отчёт ответственного чата, не повторная проверка здесь и не подтверждение выпуска в production. На момент ответа производство гостиницы не переключалось.
