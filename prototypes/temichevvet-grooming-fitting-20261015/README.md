# Публичный сайт груминга TemichevVET

Сайт для pet.temichevvet.ru. Сохранён выбранный фотографический вариант: 38 пород собак, 8 разделов для кошек, 138 иллюстративных референсов, сравнение разделителем, избранное и пожелания на устройстве, сценарный помощник и переход в клиентский кабинет.

Сайт получает конфигурацию через `/v1/public/grooming/catalog`. Выбранная порода, образы и пожелания передаются через короткоживущий draft в `https://cabinet.temichevvet.ru/portal/grooming`. Клиентская сессия и реальная запись обслуживаются существующим шлюзом и отдельным расписанием груминга в CRM. Секретов и прямого доступа к базе в браузере нет.

Реальные услуги, цены и графики пользователь заполнит в CRM. До заполнения самозапись остаётся выключенной; публикация сайта не означает появления свободных интервалов. AI-примерка по фото не входит в этот выпуск. Изображения каталога — ориентиры для обсуждения, не обещанный результат и не портфолио.

Размещение: статический `dist/client` на RU 193.188.23.65, отдельный Nginx vhost pet.temichevvet.ru. Скрипт узкого выпуска — `deploy/grooming-site/release.py` в корне репозитория. Постоянные API, Web CRM, owner-gateway, базы, MAX и PWA грумера этим скриптом не заменяются. На сервере сохраняются копия конфигурации Nginx и квитанции.

Проверки: `npm run build`, `npm run test:sites`, браузерные сценарии и публичный HTTPS после выкладки. Исторические исходники и прототипы сохранены в прежней рабочей копии.
